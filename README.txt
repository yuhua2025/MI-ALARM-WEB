小米小爱智能闹钟 · LED 灯板更换全记录
======================================

一个纯静态站点，零依赖、可离线打开。

目录结构
--------
  index.html          页面本体（单页，含全部内容）
  assets/style.css    样式
  assets/main.js      交互脚本（灯箱 / 滚动进度 / 动画）
  assets/img/         31 张实拍图（已压缩，最长边 1600px，JPEG）

本地查看
--------
  方式一：直接双击 index.html 用浏览器打开
  方式二（推荐，避免个别浏览器本地文件限制）：
      在该目录下执行  python3 -m http.server 8080
      然后访问        http://127.0.0.1:8080

部署到线上（任选其一）
----------------------
  1. 静态托管平台：把整个目录拖进去即可
     - Vercel / Netlify：直接拖拽文件夹上传，或用 CLI
     - Cloudflare Pages / GitHub Pages：推到仓库后在设置里指定该目录
  2. 任意 Web 服务器：把目录内容上传到网站根目录（如 Nginx 的 html/）
  3. 对象存储 + CDN（腾讯云 COS / 阿里云 OSS）：
     上传全部文件，把 index.html 设为默认首页，开启静态网站功能

小提示
------
  - 图片为相对路径，请保持 index.html 与 assets/ 的相对位置不变
  - 页面自适应手机端；顶部导航、灯箱（← → 换图、Esc 关闭）均可正常使用
  - 购买链接为淘宝/闲鱼短链，如需替换直接改 index.html 中 .buy-row 里的 href
